Know the bill before you sign for it

Governed doesn't have to mean expensive — but it does have to mean knowable. The same agent architecture runs from roughly a hundred dollars a month in a disposable sandbox to several thousand in a zone-redundant production estate, and the difference is four or five variables rather than a redesign.

02The five knobs that move the needle

  1. API Management SKU. Developer ~$50 (no SLA) versus Premium ~$2,800 per unit. Premium buys Internal VNet and availability zones — if you only need VNet, Standard v2 is ~$700.
  2. AI Search tier × units. Basic 1×1 ~$75 versus Standard 1×3 ~$735. Replicas buy query SLA; partitions buy index size. Scale the one you actually need.
  3. Private endpoints. ~$9.50/mo each, so ~$57 for a typical six. Turning them off saves that and costs you network isolation — demo data only.
  4. Log Analytics retention and ingest. 5 GB/mo free, ~$2.53/GB after, plus ~$0.12/GB/mo past 31 days. Reuse the platform workspace rather than standing up your own.
  5. Environments and agents. Mostly licensing and tenant capacity rather than Azure spend — but each production Dataverse environment draws ~1 GB from tenant capacity, with overage around $40/GB/mo.
Cheapest honest evaluation: the sandbox profile — ~$100 for a month, or a few dollars torn down the same afternoon. It runs the full twelve-proof test suite for about five cents in tokens.

05Billed outside Azure

Power Platform and Copilot Studio are licensing and tenant capacity, not Azure metering — they never appear on the Azure invoice. Premium Power Platform runs ~$5–20 per user per month; Copilot Studio runs on a licence or message packs at roughly $200 per 25,000 messages.

You can turn it off. terraform destroy per module, in reverse order. Destroy AI Search and API Management first — those are what stop the meter. Key Vault purge protection holds a soft-deleted vault, and its name, for 90 days with no force-purge, which is exactly why the sandbox profile sets it to false: apply, demo, destroy, rebuild the same day.
