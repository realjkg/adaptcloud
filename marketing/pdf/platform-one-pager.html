Your agents are identities. Govern them like it.

Most agent projects die in the gap between “it answered the question” and “it can touch production data.” Adapt Cloud closes that gap with infrastructure rather than policy documents: agents deploy inside a real Azure landing zone, each with its own Entra identity, behind guardrails that deny the bad deployment instead of reporting on it next quarter.

Agents as first-class identities

One Entra Agent ID or user-assigned managed identity per agent. No shared service principals, no impersonated users, no client secrets — federated credentials instead.

A real landing zone

An Application landing zone under an Application Platform management group — created idempotently if your tenant doesn’t already have one, then peered to your connectivity hub.

Policy as code, in Deny

Seven definitions in one initiative, assigned at management-group scope — so it covers the workloads nobody told you about.

Low-code first

Power Platform Managed Environments with DLP classifying the full connector catalog into Business, Non-Business and Blocked, plus APIM-fronted custom connectors from your own OpenAPI specs.

Traceable by design

Central Log Analytics, per-agent Application Insights, diagnostic settings enforced by policy, Defender for Cloud AI threat protection, Purview/DSPM hooks.

Human in the loop

Sensitive operations sit behind an APIM policy requiring an approver header. An agent can prepare a payout. It cannot issue one alone.

02What gets deployed

  • Application Platform landing zone — management group, vended workload subscription, spoke network, central Log Analytics, platform managed identities.
  • Policy-as-code initiative — allowed regions, approved model deployments, deny public network access, deny local auth on Cognitive Services, require diagnostic settings, require ownership and classification tags, audit managed identity.
  • Insurance workload landing zone — Power Platform Managed Environment and connector DLP, APIM-fronted API connectors, Copilot Studio / AI Foundry agents each with their own identity, Key Vault, Application Insights, private endpoints.
  • Control-mapping matrix — control-by-control traceability from each CAF recommendation to the file implementing it.
