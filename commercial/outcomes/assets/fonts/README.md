# Space Grotesk website typography

Retrieved 30 September 2026 from Google Fonts. Original TTF files are bundled without modification under the included SIL Open Font License.

The live Adapt Cloud site loads Space Grotesk weights 300-700. Its CSS uses `.heading-xlarge` and `.heading-medium` at 400; `.text-size-large` at 500; and `.text-size-medium` / `.text-size-small` at 300. The brochure maps its display headings to 400, subheadings and labels to 500, and body copy to 300. Display line height follows the website's 1.2 ratio; print sizes are adapted to the page.
